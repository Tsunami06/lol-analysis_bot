# lol-daily-bot

英雄联盟开黑群每日战报 bot。当前处于 **P0：数据通路验证** 阶段。

## P0 要验证什么

1. 国服客户端能被脚本连上（`lockfile` / 进程参数）
2. 「名字#编号」能解析成 puuid
3. 能拉到 5 个人昨天的同队对局
4. 确认「海克斯大乱斗」的 `queueId`

这四点过了，后面的评分、渲染、微信推送才有意义。

## 前置条件

- Windows，英雄联盟客户端已启动并**登录完成**（不是停在登录框）
- Node.js 20+（`node -v` 能输出即可）
- 不需要 `npm install`，脚本零依赖

## 用法

1. 复制 `config/players.example.json` 为 `config/players.json`，填入 5 个人的召唤师名：

```json
[
  { "nickname": "老王", "summoner": "召唤师名#12345" }
]
```

> 名字必须是完整的 `游戏名#编号`，编号不是 QQ 号，是客户端里名字后面的那串数字。

2. 双击 `run-p0.cmd`，或在终端里：

```bat
node scripts\p0-lcu-spike.mjs
```

3. 看控制台输出，并把 `fixtures\<日期>\summary.json` 发出来。

## 常用参数

| 参数 | 说明 |
|---|---|
| `--probe` | 只验证连通性，不拉战绩 |
| `--lockfile "D:\路径\lockfile"` | 手动指定客户端路径（自动探测失败时） |
| `--deep` | 全盘兜底扫描（慢，30 秒到几分钟） |
| `--date 2026-10-27` | 指定统计某一天，默认「昨天」 |
| `--count 50` | 每人拉多少场，默认 100 |
| `--players 路径` | 指定玩家配置 |
| `--out 路径` | 指定输出目录，默认 `fixtures/` |
| `--selftest` | 不连客户端，只跑内部自检 |

## 输出怎么看

```
--- 队列号分布（近期全部对局） ---
  灵活排位(440)           12 场
  极地大乱斗(450)          8 场
  未知模式(2400)           5 场      ← 这个大概率就是海克斯大乱斗
```

如果「未知模式」的 id 在海克斯大乱斗对局里稳定出现，就可以把它写进配置映射。

## 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 没有找到客户端 | 客户端没开，或装在非常规路径 | 先开客户端；仍不行用 `--lockfile` 指向安装目录下 `lockfile` |
| HTTP 404 current-summoner | 客户端停在登录界面 | 登录完成后再跑 |
| 查无此人 | 名字格式不对，缺 `#编号` | 客户端个人资料里复制完整名字 |
| 昨天 0 局 | 客户端战绩同步有延迟，或当天确实没打 | 用 `--date` 换个日期验证 |
| 只拉到 20 场 | 客户端分页限制 | 一般够用，不够再翻页 |
